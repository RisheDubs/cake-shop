# 0005. Solo Scrumban with 1-week sprints on GitHub Projects

- Status: accepted
- Date: 2026-10-27

## Context
One developer, one client, fixed rough deadline, lots of learning. Full Scrum ceremonies are overhead for a team of one; pure Kanban gives the client no rhythm of demos.

## Decision
Scrumban: weekly sprints (goal, review, retro) on a Kanban board with WIP limits, all in GitHub (Issues, Milestones, Projects), which is free. Details in docs/process/workflow.md.

## Consequences
- Weekly demo to the client keeps them involved and catches misunderstandings early.
- Everything (backlog, decisions, history) lives in the repo, which feeds the final documentation.
